# Instagram Follow Manager (Private)

Private repository for personal automation tools.

## Included

- Python automation scripts for follow management
- Local Streamlit dashboard
- Debug tools

## Setup

```bash
pip install -r requirements.txt
python private_automation.py
# or
streamlit run private_dashboard.py
```

## Security Notes

- Do not commit personal Instagram data exports.
- Do not commit browser session profiles.
- Keep this repository private.
